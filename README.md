# 🛰️ Satellite Telemetry Analysis System\n\nReal-time anomaly detection and forecasting using Prophet and Isolation Forest with MongoDB.\n\n## Quick Start\n\n### 1. Install Dependencies\n```bash\npip install -r requirements.txt\n```\n\n### 2. Configure MongoDB\nCreate `.env` from `.env.example` and add your MongoDB URL:\n```env\nMONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/db\n```\n\n### 3. Start Backend\n```bash\npython -m uvicorn app.main:app --reload\n```\n\n### 4. Open Frontend\nOpen `frontend/index.html` in your browser\n\n## Project Structure\n\n```\napp/\n  ├── main.py       → FastAPI REST API\n  ├── database.py   → MongoDB operations\n  ├── models.py     → Model loading (Isolation Forest)\n  ├── forecast.py   → Prophet forecasting\n  ├── inference.py  → Anomaly detection\n  ├── schemas.py    → Data validation\n  └── config.py     → Configuration\n\nfrontend/\n  └── index.html    → React dashboard\n\nmodels/\n  ├── isolation_forest.pkl  → Anomaly detection model\n  └── prophet_model.pkl     → Time series forecast model\n```\n\n## API Endpoints\n\n| Method | Endpoint | Purpose |\n|--------|----------|----------|\n| POST | `/api/telemetry` | Submit telemetry + detect anomalies |\n| GET | `/api/telemetry/recent` | Get recent telemetry records |\n| GET | `/api/anomalies` | Get detected anomalies |\n| POST | `/api/forecast` | Generate 24-hour forecast |\n| POST | `/api/train` | Train Prophet model |\n| GET | `/health` | System health check |\n\n## Data Format\n\n### Telemetry Input\n```json\n{\n  \"battery_voltage\": 12.5,\n  \"bus_voltage\": 5.0,\n  \"wheel_rpm\": 150.0,\n  \"current\": 2.3,\n  \"wheel_temperature\": 45.2\n}\n```\n\n## Environment Variables\n\n```env\nMONGODB_URI=your-mongodb-url\nDATABASE_NAME=satellite_telemetry\nLOG_LEVEL=INFO\n```\n\n## Troubleshooting\n\n**MongoDB Connection Error**\n- Check `.env` for correct MongoDB URL\n- Verify network access in MongoDB Atlas\n\n**Port Already in Use**\n```bash\npython -m uvicorn app.main:app --port 8001\n```\n\n**Prophet Model Not Found**\n- Place trained `prophet_model.pkl` in `models/` directory\n- Restart the backend\n\n## Features\n\n✅ Real-time anomaly detection (Isolation Forest)  \n✅ Time series forecasting (Prophet)  \n✅ React dashboard for monitoring  \n✅ MongoDB data persistence  \n✅ RESTful API with auto-docs  \n✅ No GPU required\n
